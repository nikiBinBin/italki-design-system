# italki Design System

This repository is the framework-neutral (pure JS) italki Design Catalog: the executable UI reference, contracts, and implementation mappings. The React implementation lives in its own repository (`italkiDesignReact`).

## Entry Points

- **Live Catalog:** https://design.italkiux.com/ — browsable components and every documented state.
- **For non-designers:** [docs/FOR-NON-DESIGNERS.md](docs/FOR-NON-DESIGNERS.md) — a three-step, copy-paste workflow for generating in-system UI with AI.
- **For AI:** [AI.md](AI.md) — self-contained instruction pack. Feed this to any AI before asking it to generate italki UI.

## Start Here

- `index.html` and `catalog.css`: the shareable visual Catalog. Keep both at the repository root because the deployed static site loads them directly.
- `docs/core/`: the authored system rules. Read `DESIGN.md`, `COMPONENTS.md`, `PATTERNS.md`, and `EXECUTION.md` in that order for a product implementation.
- `docs/reference/`: lookup material for implementation work. `COMPONENT_API.md` describes the Catalog API, `FOUNDATION_API.md` maps semantic colors to Panda tokens, `PANDA_API.md` maps component props to Panda, and `REFERENCE_CODEBASE_MAP.md` locates the current production codebases.
- `catalog-runtime/`: framework-neutral renderer, tokens, contracts, and generated API indexes used only by the Catalog and its validation tooling.
- `Assets/`: approved icons, flags, and images.
- `maintenance/`: contract generation, validation, local Catalog serving, and visual regression tests.

## Reference Boundaries

`REFERENCE_CODEBASE_MAP.md` answers where existing product and Panda code live. `PANDA_API.md` answers how a specific Catalog component and prop translate to Panda. They are complementary, not duplicate codebase maps.

## Generated Files

`docs/reference/COMPONENT_API.md`, `docs/reference/FOUNDATION_API.md`, `docs/reference/PANDA_API.md`, and the JSON indexes in `catalog-runtime/` are generated by `npm --prefix maintenance run build:api`. Do not edit them by hand.

`test-results/` and `maintenance/test-results/` are ignored local test artifacts. They are not design-system source files.
