# Panda API Mapping

> Generated by `maintenance/scripts/generate-component-api.mjs`. Do not edit manually.

This is the code-level translation layer between the Catalog reference API and the current Panda component library. It is read-only: it does not change Panda, existing wrappers, or any application theme.

- `direct`: pass the stated Panda prop or native attribute through the approved wrapper.
- `adapter`: use the named Panda composition or existing product adapter; Catalog and Panda APIs are not interchangeable.
- `catalog-only`: fixture state or demo control only; never copy it into production code.
- `gap`: no confirmed Panda API. Report the gap and do not create a local visual substitute.
